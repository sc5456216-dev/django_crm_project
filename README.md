# 🚀 Django CRM Project

A Customer Relationship Management (CRM) system built with **Django** that helps businesses manage contacts, companies, deals, and tasks through a role-based dashboard.

---

## 📌 Features

### 🔐 Authentication & Authorization
- User Login & Logout
- Role-Based Access Control
- Admin
- Sales Manager
- Sales Representative
- Permission-based CRUD operations

---

### 👥 Contact Management
- Create Contacts
- View Contact Details
- Update Contacts
- Delete Contacts
- Search Contacts

---

### 🏢 Company Management
- Create Companies
- View Company Details
- Update Companies
- Delete Companies
- Search Companies

---

### 💼 Deal Management
- Create Deals
- View Deal Details
- Update Deals
- Delete Deals
- Deal Pipeline
- Deal Stage Tracking

---

### ✅ Task Management
- Create Tasks
- Assign Tasks
- Update Tasks
- Delete Tasks
- Track Pending Tasks

---

### 📊 Dashboard
- Total Contacts
- Total Deals
- Won Deals
- Pending Tasks
- Total Revenue
- Recently Added Contacts
- Deal Pipeline Overview

---

### 📧 Email Notifications
- Django Signals
- Automatic Email Notifications

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/sc5456216-dev/django_crm_project.git
```

```bash
cd django_crm_project
```

### Create Virtual Environment

```bash
python -m venv myenv
```

Windows

```bash
myenv\Scripts\activate
```

Linux/macOS

```bash
source myenv/bin/activate
```

---

### Install Dependencies

```bash
pip install -r requirements.txt
```

---

### Apply Migrations

```bash
python manage.py migrate
```

---

### Create Superuser

```bash
python manage.py createsuperuser
```

---

### Run the Server

```bash
python manage.py runserver
```

Open

```
http://127.0.0.1:8000/
```
